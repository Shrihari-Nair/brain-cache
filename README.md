# brain-cache

My personal knowledge dump — LeetCode solutions and AI-related learnings, all in one place.

## What's in here

- **LeetCode** — problems I've solved, with my solution and a short note on the approach.
- **AI** — code, experiments, and notes on AI/ML concepts I'm learning.

## Structure

```
leetcode/
  <problem-number>-<problem-name>/
    solution.<ext>
    notes.md
ai/
  <topic>/
    ...
```

## Why

This is my brain cache — a place to offload things I've learned so I don't have to re-learn them.
